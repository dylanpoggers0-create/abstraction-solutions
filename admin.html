Write a newsletter

With a PDF, the email says "Our latest newsletter is attached!" in your template and attaches it. Max 8 MB. It's never stored: it's sent, then gone.

Every email starts with "Hi (their first name)," and ends with "Have a question...? Just reply", "Thanks for following along, Dylan", the website link, unsubscribe link and address. You don't need to add those.

Import a week from JSON

Paste the JSON Kai sends. It's checked on the server and previewed here; nothing is saved until you load it into the editor and click Save draft.

Import format (copy this template) 
{
  "week_start": "2026-11-02",
  "week_end": "2026-11-08",
  "title": "Optional short title for the week",
  "articles": [
    {
      "headline": "Exact headline as the publisher wrote it",
      "publisher": "Publisher name, e.g. Reuters",
      "published_on": "2026-11-05",
      "url": "https://www.example.com/full-link-to-the-original-article",
      "summary": "2-3 sentences in our own words (20-600 characters). Never paste the article.",
      "why_it_matters": "Optional: one sentence on why it matters to small businesses or learners."
    }
  ]
}

Rules: dates are YYYY-MM-DD; the week is at most 14 days; 1–20 articles; links must start with https://; plain text only (no HTML); "why_it_matters" can be left out.
